# 그림자 엔진 — 구현 가이드

> 이 문서는 **"그림자 코드가 실제로 어떻게 도는가"** 를 설명하는 구현 가이드다.
> - 무엇을/왜(재미) → [기획서.md](../기획서.md)
> - 어떻게 만들 계획인가 → [개발기획서.md](../개발기획서.md) §2.1
> - 왜 이 구조인가(의사결정) → [아키텍처_결정_기록.md](../아키텍처_결정_기록.md) §2.1
> - **이 코드가 도는 원리(여기)** ← 큰 그림. 줄단위 정밀 레퍼런스는 각 파일의 XML 주석.

현재 구현은 **1차 투영(projection) 모델**이다. `IShadowEngine` 계약 뒤에 숨어 있어,
나중에 **Rotational Sweep** 엔진으로 내부만 교체해도 소비자 코드는 안 바뀐다.

---

## 1. 전체 흐름

매 프레임 아래 파이프라인이 돈다.

```
SunView(광원 위치) ──ISunPosition──▶ ShadowSystem ──▶ IShadowEngine ──▶ ShadowPolygon ──▶ ShadowView(메쉬)
                                          ▲
                                   IShadowConfig (groundY, maxShadowLength)
```

| 역할 | 타입 | 위치 |
|------|------|------|
| 광원 위치 공급 | `ISunPosition` ← `SunView` | [Core](../Assets/Scripts/Core/ISunPosition.cs) / [Sun](../Assets/Scripts/Domains/Sun/SunView.cs) |
| 매 프레임 구동 | `ShadowSystem` (`ITickable`) | [Shadow](../Assets/Scripts/Domains/Shadow/ShadowSystem.cs) |
| 그림자 계산 | `IShadowEngine` ← `ProjectionShadowEngine` | [Core](../Assets/Scripts/Core/IShadowEngine.cs) / [Shadow](../Assets/Scripts/Domains/Shadow/ProjectionShadowEngine.cs) |
| 결과 데이터 | `ShadowPolygon`, `ShadowCaster` | [Core](../Assets/Scripts/Core/ShadowPolygon.cs) |
| 표시(메쉬) | `ShadowView` (MonoBehaviour) | [Shadow](../Assets/Scripts/Domains/Shadow/ShadowView.cs) |
| 튜닝값 | `IShadowConfig` ← `ShadowConfig`(SO) | [Shadow](../Assets/Scripts/Domains/Shadow/ShadowConfig.cs) |

> 도메인 간 직접 참조는 없다. Sun↔Shadow 연결은 전부 `Core`의 인터페이스를 통하고,
> 실제 배선은 `App`의 [RootLifetimeScope](../Assets/Scripts/App/RootLifetimeScope.cs)에서 한다.

## 2. 1단계 — `ShadowSystem.Tick()` (구동)

입력을 모아 엔진을 호출하고, 결과를 렌더러에 넘긴다.

```csharp
var poly = _engine.ComputeShadow(
    _sun.WorldPosition,    // 광원 위치 (SunView의 transform)
    _view.Caster,          // 박스: 중심(transform) + 크기(Size) + ownerId
    _config.GroundY,       // 바닥선 높이
    _config.MaxShadowLength);
_view.Render(poly);        // 폴리곤 → 메쉬
```

`ITickable`로 등록돼 **타이밍을 컨테이너가 통제**한다(Unity 매직 메서드에 로직을 흩지 않음 —
[개발기획서.md](../개발기획서.md) §4.7).

> ⏱️ 지금은 그림자가 시각용이라 `Tick`(매 프레임). 나중에 **밟기 판정**에 쓰이면
> 결정성을 위해 `FixedTick`으로 옮긴다.

## 3. 2단계 — `ProjectionShadowEngine` (핵심 계산)

캐스터를 **축 정렬 박스**로 보고, 그 실루엣을 바닥선(`y = groundY`)에 던진다.
순수 C#이라 MonoBehaviour·Unity 라이프사이클 없이 단위 테스트 가능하다.

### (a) 박스 네 모서리 = 중심 ± 반쪽크기

```
topLeft ●────────● topRight
        │  박스   │
bottomL ●────────● bottomR
```

### (b) 아랫변 2점은 그대로
그림자의 "발밑(가까운 변)"으로 그대로 쓴다.

### (c) 윗변 2점만 바닥에 투영 ← 알맹이
빛에서 모서리를 지나는 직선을 그어, `y = groundY`에 닿는 점을 구한다.

```csharp
Vector2 dir = P - L;                  // 빛(L) → 모서리(P), 즉 빛 반대 방향
float   t   = (groundY - P.y) / dir.y; // 직선 위에서 y가 groundY가 되는 지점
Vector2 hit = P + dir * t;            // 그림자 끝점
```

직선 방정식 `P.y + t·dir.y = groundY` 를 `t`에 대해 푼 것이다.

```
        ☀ light L
         \
          \
        P  ●  caster 윗모서리
            \
             \
──────────────●──── groundY      ← 여기 닿는 점이 그림자 끝(hit)
             hit
```

**예외 처리**
- 빛이 모서리보다 위가 아니면(`dir.y ≥ 0`) → 무한대 방지로 수평으로 `maxLength`만큼 뻗는 fallback.
- 결과 길이도 `maxLength`로 **clamp** → 빛이 지평선에 가까워도 그림자가 무한히 길어지지 않음.

### (d) 폴리곤 조립 = 사다리꼴

```csharp
{ bottomLeft, bottomRight, projRight, projLeft }
```

빛이 옆으로 갈수록 이 사다리꼴이 기울고 길어진다. (빛 위치에 따른 물리적으로 올바른 거동)

## 4. 3단계 — `ShadowView.Render` (표시)

폴리곤 점들을 메쉬 정점으로 만들고, **부채꼴(fan) 삼각분할 + 양면**으로 그린다
(winding/culling에 가려지지 않게).

- 캐스터의 transform이 이미 world-space 폴리곤을 다시 밀지 않도록,
  메쉬는 **월드 원점의 별도 오브젝트**(`<name>_ShadowMesh`)에 올린다.
- 머티리얼 미지정 시 런타임에 `Sprites/Default` 기반 반투명 검정 머티리얼을 생성.

---

## 5. 설계 포인트

- **`ShadowPolygon`(+`OwnerId`) 하나가 단일 진실**: 지금은 렌더에만 쓰지만,
  나중에 밟기 판정(`IStompJudge`)도 *같은 폴리곤*을 소비한다 → "보이는 것 = 판정되는 것"
  ([개발기획서.md](../개발기획서.md) §2.2).
- **엔진은 `IShadowEngine` 뒤에 숨음**: 단순 투영 → Rotational Sweep 교체 시
  `ShadowSystem`/`ShadowView`는 한 줄도 안 바뀐다.
- **광원의 출처는 `ISunPosition` 뒤에 숨음**: 지금은 손으로 옮기는 `SunView`,
  나중엔 궤도 계산 `SunOrbitService` — 그림자 코드는 무관.

---

## 6. 현재 한계 (의도된 단순화)

이 투영 모델은 "광원을 움직이면 그림자가 실시간 반응한다"를 검증하는 1차 구현이다.
다음은 아직 안 된다:

- **차폐물에 막혀 잘리기** 없음 — 바닥은 평평한 직선(`groundY`) 하나로 흉내. 실제 플랫폼 기하 미반영.
- **캐스터 = 단순 박스** — 실제 스프라이트 모양/피벗과 자동 동기화 안 됨(`Size`를 수동 일치 필요).
- **윗변만 투영** — 일반 실루엣이 아니라 박스 윗변→바닥선 사다리꼴.
