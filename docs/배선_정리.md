# 배선 정리 (Wiring Map)

> **"어떤 스크립트가 어디에 붙고, 왜 거기 붙으며, DI로 어떻게 연결되나"** 를 한눈에 보는 문서.
> 새 스크립트가 씬에 붙거나 DI 등록이 바뀌면 **여기를 같이 업데이트**한다 (CLAUDE.md 규칙).
> 알고리즘/원리는 [그림자_엔진.md](그림자_엔진.md), 구조 의사결정은 [아키텍처_결정_기록.md](../아키텍처_결정_기록.md).

---

## 1. 씬 오브젝트 ↔ 컴포넌트 (무엇이 어디에 붙나)

| GameObject | 붙는 컴포넌트 | 역할 | 왜 여기 붙나 |
|---|---|---|---|
| `[App]` | `RootLifetimeScope` | DI 컨테이너 부팅(조립 루트) | 앱 단일 진입점. 씬에 1개. |
| `Sun` | `SunLightSource` | 광원 **위치 공급** (`ISunPosition`) | 이 오브젝트의 transform = 광원 위치. 손으로 옮기는 대상. |
| `Caster` | `ShadowCaster` | **캐스터**(그림자 만드는 박스) + 그림자 메쉬 렌더 | 이 오브젝트가 곧 그림자를 드리우는 주체. |
| `Occluders` | `OccluderField` | 자식 `Occluder`들을 모아 차폐물 제공 (`IOccluderSource`) | 부모 1개가 자식 차폐물을 수집(`GetComponentsInChildren`). |
| `Occluders/Ground`·`Platform`·… | `Occluder` | 박스 차폐물 1개(4변을 선분으로) | 그림자가 얹히고 잘리는 표면. 반드시 `Occluders`의 **자식**. |

> 핵심 규칙: **차폐물은 `OccluderField`의 자식이어야 등록된다.** 형제/딴 데 있으면 엔진이 무시(과거 "박스 통과" 버그의 원인).

## 2. DI 등록 — `RootLifetimeScope.Configure()`

```csharp
builder.RegisterInstance(_shadowConfig).As<IShadowConfig>();                 // SO 데이터
builder.RegisterComponentInHierarchy<SunLightSource>().As<ISunPosition>();        // 씬 컴포넌트
builder.RegisterComponentInHierarchy<OccluderField>().As<IOccluderSource>();
builder.Register<RotationalSweepShadowEngine>(Lifetime.Singleton).As<IShadowEngine>(); // 순수 서비스
builder.RegisterComponentInHierarchy<ShadowCaster>().As<IShadowCaster>();
builder.RegisterEntryPoint<ShadowSystem>();                                 // ITickable 구동
```

| 등록 방식 | 언제 쓰나 | 여기서 |
|---|---|---|
| `RegisterInstance(asset).As<I…>()` | 인스펙터 SO 데이터 배포 | `ShadowConfig` → `IShadowConfig` |
| `RegisterComponentInHierarchy<T>().As<I…>()` | **씬에 붙은** MonoBehaviour 주입 | `SunLightSource`, `OccluderField`, `ShadowCaster` |
| `Register<T>(Singleton).As<I…>()` | 순수 C# 서비스 | `RotationalSweepShadowEngine` |
| `RegisterEntryPoint<T>()` | 매 프레임/초기화 로직(`ITickable` 등) | `ShadowSystem` |

> 모든 연결은 **인터페이스(`Core`)** 로. 소비자는 구현 클래스를 모른다. 배선은 오직 여기(App)에서.

## 3. 데이터/제어 흐름 (요약)

```
SunLightSource ──ISunPosition──┐
OccluderField ─IOccluderSource─┐
                               ├─▶ ShadowSystem ─▶ IShadowEngine ─▶ ShadowPolygon ─▶ IShadowCaster(ShadowCaster) 렌더
ShadowConfig ─IShadowConfig────┘
```
자세한 단계는 [그림자_엔진.md §1–4](그림자_엔진.md).

## 4. 스크립트 역할 일람 (전체 15)

| 스크립트 | 종류 | 역할 | 부착/등록 |
|---|---|---|---|
| `ISunPosition` | 인터페이스(Core) | 광원 위치 계약 | — |
| `IShadowEngine` | 인터페이스(Core) | 그림자 폴리곤 계산 계약 | — |
| `IShadowCaster` | 인터페이스(Core) | "그림자 만드는 것" 계약(캐스터+렌더) | — |
| `IOccluderSource` | 인터페이스(Core) | 차폐물 선분 공급 계약 | — |
| `CasterShape` | struct(Core) | 캐스터 데이터(중심·크기·ownerId) | — |
| `ShadowPolygon` | struct(Core) | 결과 폴리곤(+ownerId), 단일 진실 | — |
| `Segment` | struct(Core) | 차폐물 선분 데이터 | — |
| `RootLifetimeScope` | LifetimeScope(App) | 조립 루트, 부팅·배선 | `[App]`에 부착 |
| `SunLightSource` | MonoBehaviour(Sun) | transform→광원 위치 | `Sun`에 부착, `ISunPosition`로 등록 |
| `RotationalSweepShadowEngine` | 순수 서비스(Shadow) | sweep 폴리곤 계산 | `IShadowEngine`로 등록 |
| `ShadowSystem` | 순수 서비스(Shadow) | 매 프레임 구동(`ITickable`) | EntryPoint 등록 |
| `ShadowCaster` | MonoBehaviour(Shadow) | 캐스터 데이터(`Shape`) 제공 + 메쉬 렌더 | `Caster`에 부착, `IShadowCaster`로 등록 |
| `ShadowConfig` | ScriptableObject(Shadow) | 튜닝값(maxShadowLength) | SO 에셋, `IShadowConfig`로 등록 |
| `Occluder` | MonoBehaviour(Map) | 박스 1개 → 4변 선분 | 차폐 박스에 부착 |
| `OccluderField` | MonoBehaviour(Map) | 자식 `Occluder` 수집 | `Occluders`에 부착, `IOccluderSource`로 등록 |

## 5. 이름 규칙 (적용됨)

> 역할이 이름에 드러나게. **모호한 접미사(`~View`/`~Manager`/`~Helper`) 금지.**

| 역할 | 접미사/패턴 | 예 |
|---|---|---|
| Core 계약 | `I…` (역할 단위) | `ISunPosition`, `IShadowEngine`, `IShadowCaster`, `IOccluderSource` |
| 데이터(값) | 명사, 접미사 없음 | `CasterShape`, `ShadowPolygon`, `Segment` |
| 씬 MonoBehaviour = 엔티티/공급원 | **엔티티 이름** (역할이 드러나게) | `ShadowCaster`, `Occluder`, `OccluderField`, `SunLightSource` |
| 순수 매 프레임 구동자 | `~System` | `ShadowSystem` |
| 순수 계산 | `~Engine` | `RotationalSweepShadowEngine` |
| SO 설정 | `~Config` | `ShadowConfig` |

**적용 이력 (2026-06-26 리네임)** — `~View`가 역할(위치공급/캐스터/렌더)을 못 담아 혼동되던 것 정리:
- `ShadowView` → **`ShadowCaster`** (씬의 캐스터 = 그림자 만드는 주체. 렌더는 그 안에 포함).
- 충돌 해소: struct `ShadowCaster` → **`CasterShape`**, 인터페이스 프로퍼티 `Caster` → **`Shape`** (`IShadowCaster.Shape : CasterShape` — "캐스터가 캐스터를 든다" 혼동 제거).
- `SunView` → **`SunLightSource`** (렌더 안 함, 위치 공급원; 개발기획서 §2.1의 "2D 점광원" 용어와 일치).
- 유지: `Occluder`/`OccluderField`/`ShadowSystem`/`RotationalSweepShadowEngine`/`ShadowConfig` (이미 역할이 드러남).

> 리네임은 `.cs`+`.cs.meta`를 함께 옮겨(GUID 보존) 씬 컴포넌트 참조가 안 깨지게 했다.
